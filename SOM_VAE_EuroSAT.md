# SOM-VAE для классификации спутниковых изображений EuroSAT

## Задача

Построение нейросетевой архитектуры **SOM-VAE** (Self-Organizing Map Variational Autoencoder) для классификации спутниковых изображений из датасета **EuroSAT**.

## Архитектура

### SOM-VAE концепция
- **VAE база**: автоэнкодер с латентным пространством
- **SOM модификация**: латентное пространство организовано как равномерное распределение по карте SOM
- **Кастомный лосс**: комбинация reconstruction loss, commitment loss, SOM loss и classification loss

### Компоненты модели
1. **Энкодер**: 3 сверточных блока (64→128→latent_channels) с BatchNorm и MaxPool
   - Block 1: Conv2d(3→64) → BatchNorm → ReLU → MaxPool(64→32)
   - Block 2: Conv2d(64→128) → BatchNorm → ReLU → MaxPool(32→16) 
   - Block 3: Conv2d(128→C_latent) → BatchNorm → ReLU → MaxPool(16→8)
2. **SOM слой**: GlobalSpatialSOMLayer с квантованием латентных представлений
   - Размер сетки: настраиваемый (по умолчанию 8×8 = 64 узла)
   - Латентная размерность: (channels, height, width) - настраиваемая
   - Winner-takes-all: один победитель на все изображение
   - Матричная оптимизация расчета расстояний
3. **Декодер**: 3 транспонированных сверточных блока (8→16→32→64)
   - Block 1: ConvTranspose2d(C_latent→128) → BatchNorm → ReLU
   - Block 2: ConvTranspose2d(128→64) → BatchNorm → ReLU  
   - Block 3: ConvTranspose2d(64→3) → Tanh
4. **Классификатор**: полносвязный слой для предсказания класса земного покрова
   - Flatten → Linear(C×H×W→256) → ReLU → Dropout(0.3) → Linear(256→10)

## Данные

### EuroSAT Dataset
- **Тип**: спутниковые изображения земной поверхности
- **Размер**: 64×64 RGB
- **Классы**: 10 категорий (AnnualCrop, Forest, HerbaceousVegetation, etc.)
- **Источник**: Kaggle dataset `apollo2506/eurosat-dataset`

### Предобработка
- Изменение размера до 64×64
- Нормализация: `mean=[0.5, 0.5, 0.5]`, `std=[0.5, 0.5, 0.5]` (диапазон [-1, 1])
- Разделение: train/validation

## Гиперпараметры

### Архитектурные параметры
- `grid_size`: размер SOM сетки (по умолчанию 8×8 = 64 узла) - **настраиваемый**
- `latent_dim`: размерность латентного пространства (channels, height, width) - **настраиваемый**
  - Пример: (128, 8, 8) = 128 каналов, 8×8 пространственное разрешение
- `num_classes`: количество классов (10 для EuroSAT)
- `in_channels`: количество входных каналов (3 для RGB)

### Обучающие параметры
- `batch_size`: размер батча (128)
- `epochs`: количество эпох обучения (15)
- `learning_rate`: скорость обучения (1e-3)
- `alpha`: вес commitment loss (1.0) - **настраиваемый**
- `beta`: вес SOM loss (1.0) - **настраиваемый**  
- `gamma`: вес classification loss (1.0) - **настраиваемый**

### Оптимизатор
- **AdamW** с weight decay для лучшей регуляризации
- Двухэтапное обучение: lr=1e-3 → lr=1e-4 (опционально)

## Функция потерь

```
total_loss = reconstruction_loss + alpha * commitment_loss + beta * som_loss + gamma * classification_loss
```

### Компоненты
1. **Reconstruction Loss**: MSE между оригиналом и реконструкцией
2. **Commitment Loss**: MSE между z_e и z_q
3. **SOM Loss**: регуляризация соседей на карте
4. **Classification Loss**: кросс-энтропия для классификации

## Метрики оценки

- **Accuracy**: точность классификации
- **NMI**: Normalized Mutual Information (качество кластеризации)
- **Reconstruction Quality**: визуальное качество восстановления

## Важные замечания

### Особенности реализации
- **Global SOM**: один победитель для всего изображения
- **Матричная оптимизация**: эффективный расчет расстояний
- **Инициализация SOM**: реальными данными из первого батча
- **Визуализация**: активации SOM, реконструкции, прогресс обучения

### Потенциальные проблемы

- **Отсутствие сохранения** модели
- **Необходимость early stopping**
